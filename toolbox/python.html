viewof noise = Inputs.range([0.1, 3], {value: 0.4, step: 0.1, label: "noise (°C)"})

How much each thermometer reading wobbles at random, in °C. More noise: messier points, and a less certain fit.

viewof interval = Inputs.range([5, 60], {value: 15, step: 5, label: "readings every (s)"})

Seconds between one reading and the next. The longer the wait, the fewer points you get.

viewof cooling_time = Inputs.range([60, 400], {value: 240, step: 10, label: "cooling time τ (s)"})

How slowly the tea cools: after τ seconds the gap to room temperature has shrunk to about 37%. Larger τ means slower cooling. This is the number the fit has to find.

NoteWords
  • noise (σ): how much one reading can be off. The bars on the points.
  • fit: finding the numbers that bring a curve closest to the data.
  • cooling time (τ, tau): how fast the tea cools. Larger means slower.
  • residual: data minus fit, point by point (lower panel).
  • χ²: around 1 (green) the fit agrees with the bars; higher (amber, red) something is off.
  • function, lambda, dictionary: a recipe with inputs; a tiny unnamed recipe; a labelled collection like laws["newton"].
NoteAbout this page

Python runs inside your browser (Pyodide, WebAssembly): nothing you type is sent to a server. The first visit downloads tens of MB of Python files and page libraries from a public content delivery network (jsDelivr), which can see your IP address; later visits use the browser cache. The data are simulated. Real Mosaicus measurements come next.

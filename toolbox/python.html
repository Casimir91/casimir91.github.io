Python Lab

A cup of tea cooling down. Run Python in your browser, change the code, watch the graph change.

Fit Newton’s law of cooling with Python, right here in the browser. Nothing to install.

Press ▶ Run on any block, or edit the code first and then run it. Blocks run from top to bottom: if you change an early one, run the later ones again.

0 · The look

Every graph below takes its colours and fonts from this block. Change a colour, run this block, then run the others again.

1 · The experiment

A cup of tea cools in a room. One temperature reading every 15 seconds, each with an uncertainty sigma. The numbers are simulated with the same model as the Mosaicus simulator; \(\tau = 240\ \text{s}\) is the value the simulation uses. Can the fit find it?

Try: change sigma from 0.4 to 2, then run. Points scatter more and the error bars grow.

2 · Fit Newton’s law

\(T(t) = T_a + (T_0 - T_a)\,e^{-t/\tau}\). Which values of \(T_a\), \(T_0\), \(\tau\) describe the data best?

Try: change the starting guess p0, for example the last number from 100 to 5000. A fit needs a reasonable starting point: with a bad one it can run away to absurd values.

3 · Check the model

A good model leaves residuals that look like random noise inside the error bars. The reduced \(\chi^2\) puts a number on it: around 1 means the scatter matches the error bars, much larger means the model or the error bars are wrong.

Try: in step 2 replace np.exp(-t / tau) with 1 / (1 + t / tau), a different curve, and run steps 2 and 3 again. The residuals show a pattern and \(\chi^2\) jumps far above 1.

4 · Straighten it with a logarithm

Taking the logarithm of \(T - T_a\) turns the exponential into a straight line with slope \(-1/\tau\). It is the same view as \(\ln(T - T_a)\) in Mosaicus.

Look at the error bars: they grow as the tea cools, because the same \(\sigma\) weighs more on a smaller \(T - T_a\). Try: add , w=1/dy inside np.polyfit(...) and compare \(\tau\) with step 2. If \(T - T_a\) ever drops to zero or below, the logarithm breaks: a real limit of this method.

5 · Make it yours

Change one thing in step 1, then run steps 1 to 4 again:

  • the noise: sigma = 0.4 → 2. What happens to the uncertainty of \(\tau\) in step 2?
  • fewer points: np.arange(0, 600, 15.0) → np.arange(0, 600, 60.0)
  • a faster cooling: tau = 240.0 → tau = 120.0
  • the look: in step 0 swap a colour, or set "axes.grid": False, and run everything again.
NoteWords you just used
  • array: a list of numbers you can compute with all at once (t, T).
  • function: a recipe with inputs and one result (model).
  • fit: finding the parameters that bring a function closest to the data.
  • uncertainty (sigma, error bar): how much a reading can be off.
  • residual: data minus model, point by point.
  • reduced χ²: residuals measured in uncertainties; around 1 is a good fit.
  • linearisation: a change of variable that turns a curve into a straight line.
